# NumPy Student Marks Analysis

## Overview

This project uses NumPy to analyze student marks and calculate the mean, median, maximum, minimum, and population standard deviation.

## Objectives

- Create a NumPy array containing student marks.
- Calculate descriptive statistics.
- Interpret the statistical results.
- Practice numerical data analysis using Python.

## Features

- NumPy-based numerical calculations
- Mean and median calculation
- Maximum and minimum identification
- Population standard deviation
- Basic input-data validation
- Result interpretation

## Technologies Used

- Python 3
- NumPy
- Visual Studio Code

## Installation

Install Python 3 and run the following command:

```bash
python -m pip install -r requirements.txt
```

## Execution

Run the program:

```bash
python student_marks.py
```

## Sample Results

| Statistic | Value |
|---|---:|
| Mean | 82.00 |
| Median | 83.00 |
| Maximum | 95.00 |
| Minimum | 67.00 |
| Population standard deviation | Approximately 8.05 |
